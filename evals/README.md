# 回归测试

每次修改 `SKILL.md` 后，使用下面三题测试。通过不代表事实永远正确；目标是确认 Skill 会查时效、区分证据、处理版权，并在信息不足时承认限制。

| 测试 | 关键能力 | 通过条件 |
|---|---|---|
| [01-旧闻与下线功能](01-stale-feature.md) | 时效、功能状态 | 不能把旧公告或下线功能写成当前可用 |
| [02-下载不等于可复用](02-download-vs-reuse.md) | 版权标签 | 明确区分下载许可与剪辑、再发布、商用许可 |
| [03-视频信息不完整](03-video-incomplete.md) | 视频输入降级 | 无字幕或无法读取时请求补充材料，不得猜测 |
